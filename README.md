# ARJUN & MEERA - Digital Wedding Invitation

A premium, elegant, and interactive digital wedding invitation built for **Arjun and Meera**.

## Features

- **Cinematic Entrance Curtain:** A luxurious "Tap to Open" experience with curtain animations.
- **Interactive Scratch-to-Reveal:** Guests can scratch a card to reveal the wedding date and couple details.
- **Responsive Countdown:** Counting down to the big day (handles past dates gracefully).
- **Dynamic Program Timeline:** Elegant display of wedding events.
- **RSVP Form:** Fully functional frontend form with validation and feedback.
- **Mobile-First Design:** Optimized for WhatsApp and mobile browser sharing.
- **Premium Animations:** Smooth transitions and scroll-triggered reveals.
- **Configurable Data:** All content is managed through `js/invitation-data.js`.

## Tech Stack

- Vanilla HTML5
- CSS3 (Custom Properties, Flexbox, Grid, Animations)
- Vanilla JavaScript (Intersection Observer, Canvas API, Pointer Events)

## How to Customize

1. Open `js/invitation-data.js`.
2. Update the `invitationData` object with your details.
3. Replace placeholder images in `assets/images/`.
4. Deploy the files to any web host.
